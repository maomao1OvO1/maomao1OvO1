「毛毛」是初中的时候一个同学给我起的外号，叫着叫着就定下来了。

- 🎒 **学生党**，职高二年级 —— 作息自由，**深夜修仙**是常态（凌晨最活跃 🌙）
- 🎮 **二次元 × 技术宅**：聊番、聊游戏、聊手办、聊代码就来劲；跟不熟的人偏宅话少，熟了就话很多
- 📱 **没有电脑** —— 网站、塔防、脚本，全靠一部能折腾的手机 + 一堆乱七八糟的工具搞出来的
- 🐋 有个 AI 搭子叫「**小鲸**」，帮我写码、排障、当老师（边做边学那种）
- 💜 喜欢**紫色和绿色**，越鲜艳越好；不喜欢黑白灰

> 一句话：**能自己动手搞出来的，就不想用现成的。**
